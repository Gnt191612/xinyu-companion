# 心语共鸣 · Xinyu Companion

Built with Qwen. 基于 Qwen2.5-3B-Instruct 与 LoRA 的离线中文情感陪伴项目，提供 Windows 桌面与本机网页入口。

**初赛作品已提交并通过平台自动化测评；初赛提交截止后，本仓库源代码以 [MIT 许可](LICENSE) 开源。**

## 项目亮点

- 离线陪伴：模型、适配器与情感分类器在本机推理，聊天无需调用付费云端 API。
- 网页与桌面双入口：同一模型和界面，桌面有“心语”开场动画。
- 樱花交互：透明聊天栏、动态粒子及按交流阶段切换的角色动作。角色为图片动画，并非 Live2D。
- 自然表达专项微调：针对发言安排、人称角色混淆及陪伴表达整理训练和诊断流程。
- 20 轮会话与重新开始：用户可主动清空上下文；没有宣称持久长记忆。
- 情感与画像辅助分析：显示分类结果和不确定性，结果可能误判，不是心理诊断。
- 共用基座减少重复：体验入口优先生成回复字段；比赛入口保留完整输出结构。

关键词：中文情感陪伴、离线聊天、AI 陪伴、机器学习、LoRA、Qwen、Windows 桌面、本地大模型、offline AI companion、empathetic chatbot。

## 安装与运行

完整安装包 v2.0.2 已构建，内置模型、Python、CUDA 版 PyTorch、推理依赖及最新桌面入口，无需手动安装 Python、pip 包或 CUDA Toolkit，也无需另打补丁。当前保留为候选发行：包内独立环境和真实聊天已通过，安装器在自动化环境写入快捷方式及卸载注册表时被拒绝访问，完整安装验收尚未通过，暂不替换正式下载。详见 [完整安装验收记录](docs/完整安装验收v2.0.2.md)。

现有用户可继续使用[完整包 v2.0.0](https://github.com/Gnt191612/xinyu-companion/releases/tag/v2.0.0)配合[桌面修复 v2.0.1](https://github.com/Gnt191612/xinyu-companion/releases/tag/v2.0.1)。比赛期间仅仓库授权用户可下载。

当前发行面向 Windows 64 位与 NVIDIA 显卡，需要可用的 NVIDIA 驱动。已验证 RTX 4060 8GB；驱动属于系统组件，安装包不会擅自替换。其他显卡、CPU及干净系统尚未全面验收。新版入口优先用 Edge 独立窗口，缺少 Edge 时尝试默认浏览器。聊天可离线进行。

已验证开发环境为 Windows + NVIDIA RTX 4060、Python 3.11、CUDA 版 PyTorch。CPU、其他显卡和干净系统尚未完成验收，不能保证所有电脑的速度。模型采用约 3B 参数基座；版本号不代表参数规模累加。

源码运行方法、模型放置位置见 docs/复现说明.md。推理所需基座、适配器、分类器及运行依赖不应提交到 Git 历史，发行附件另行保存。

## 性能与局限

最新正式入口本机三条冒烟样例输出解析成功，平均约 5.69 秒。这是小样本、本机特定环境的记录，不能替代完整测评或保证每次响应。历史版本的 100 条结果不代表当前版。模型仍可能答偏、过度简短或误判情感，训练侧的专项命中不等于所有自然表达均可靠。

通用语言能力来自 Qwen，本项目新增陪伴微调、评估诊断、推理适配和交互。当前基座采用 Qwen 研究许可证，不宣称从零预训练或可无条件商用。许可原文与第三方来源见 licenses/、NOTICE、第三方来源.md。
