## 安装包体验

下载 Releases 中 Xinyu-Setup-v2.0.0.exe 及同名全部 .bin 分卷，放在同一目录，双击 exe 安装。无需另外安装 Python；需要 Windows 64 位、NVIDIA 驱动、可用显存及磁盘空间。安装后模型加载和聊天均离线。安装包正在独立目录验收，结果记录在发行说明，不能用开发环境成功代替安装验收。

## 源码体验的文件位置

- 原始 3B 基座：participant/model/，完整模型与分词器11个文件。
- 指定 step160 适配器：participant/adapter/。
- 分类器：participant/classifiers/latest.joblib 与 history.joblib。
- 体验配置：将 体验/config.example.json 复制为 体验/config.json。
- 私有历史下载：tmp/恢复下载/；恢复相对目录前先核对 SHA256 和 ZIP 完整性。

基座可使用 `python 获取基座.py --target participant/model`。脚本通过命令行 HTTP 客户端下载、验证大小和 SHA256，完整文件验收后删除本文件的下载分段。分段不是训练输入。基座许可证在下载文件及 licenses/ 内。

## 继续训练

私有训练历史发行附件含配置、适配器、记录和陪伴训练资源，恢复步骤见 训练备份与空间管理.md。官方原始数据不随源码公开；必须保留本机合法取得的 train/val 文件或再次从官方授权入口获得。仅克隆源码不足以重现训练。

coverage_round 从 clean3b_candidate/adapter 起步，使用153条样本、160优化步、rank16、all-linear、4位训练、学习率1e-5。开发集被用于选轮，不能宣称它是完全未见的最终测评集。更改数据、提示、基座、量化或加载方式后必须重新验收。继续实验请用新输出目录，勿覆盖已提交的 step160。

本机环境版本见 requirements.txt；训练所需 Python/CUDA 驱动需按机器安装。推理发行环境另由 tools/build_installer.py 收集实际依赖。平台 start.sh 使用 Linux conda_env，Windows 不执行此脚本。
