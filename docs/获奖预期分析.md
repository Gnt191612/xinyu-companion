# 第二版获奖预期分析

结论：具备完整产品展示与参赛潜力，目前没有足够证据认定达到全国一等奖水平，不给出无法验证的获奖概率。

2025 年共 1143 支队伍，50 支进入全国决赛，中山大学 AgentR1 获技术一等奖。主办方报道强调互动性、完成度与社会应用价值。公开报道没有提供与心语同一测试集下的模型指标，不能据此计算本项目获奖概率。
来源：https://news.nankai.edu.cn/ywsd/system/2025/12/10/030070099.shtml

心语的可展示优势：离线推理、桌面和网页双入口、完整视觉交互、角色及发言安排专项训练、可追溯版本记录。本机三例格式冒烟平均约 5.69 秒，仅证明该环境下链路运行。

主要短板：官方新提交仍待测评；缺少当前版本在独立充分样本中的人称/角色混淆错误率、与原始基座的公平对照、共情质量及多轮泛化结果；情感分类存在误判；UI 不能代替模型评分，3B 微调也不自动构成技术创新。

更可信的获奖预期判断需等待官方测评分数和排名，并补齐当前版固定留出集、基座对照和消融分析。答辩应说明为什么设计有效、失败边界及离线成本，而不强调迭代版本数量。已提交权重保持冻结，不为宣传修改测评镜像。
