# 复现说明

## 固定来源与环境

基座为 Qwen/Qwen2.5-1.5B-Instruct，固定仓库revision：`989aa7980e4cf806f80c7fef2b1adb7bc71aa306`。原始 `model.safetensors` SHA256：`dd924a11b4c220f385b51ffa522daea7c9f3d850e31b162bb5661df483c6d3ee`。

本机已使用 Python3.11、PyTorch2.6 CUDA12.4、Transformers5.13.0、PEFT0.21.2、scikit-learn1.7.2。`requirements.txt` 是这组记录，不声称其他机器能完全复现数值。云端实际使用 Python3.12、PyTorch2.10 CUDA12.8、Transformers4.57.6、PEFT0.17.1、scikit-learn1.7.2；未为迁就本机版本整体升级比赛镜像。

准备阶段可以联网安装和下载；训练/推理加载仅本地文件。`获取基座.py` 从官方仓库取得固定revision的完整模型文件并核验权重，避免原下载工具只取得权重而遗漏分词器。该准备步骤需要网络和约3GB磁盘/流量，不会自动在聊天或推理时运行。

## 数据与训练

从官方授权入口自行取得 `train_public.jsonl` 和 `val_public.jsonl`，分别放在 `数据/train/` 和 `数据/val/`。公开包不附这些文件。然后：

```bash
python 获取基座.py
python prepare_data.py
python train_classifiers.py
python train_lora.py --steps 512 --sample-limit 2048 --learning-rate 0.0001 --output-dir 实验/复现512 --merged-output participant/model
```

训练需要CUDA GPU；已在8GB显存机器完成。配置包括 seed42、rank8、alpha16、dropout0.05、q_proj/v_proj、bf16、梯度累积4、最大1536token。超过640token的目标被排除，目标JSON不截断。512步对应2048个微批次样本，不是18653个训练点全量训练。日志目录已存在时拒绝覆盖，另指定新目录。

验证：

```bash
python verify_offline.py 数据/processed/val_100_inputs.jsonl 实验/复现验收
python evaluate_predictions.py 实验/复现验收/submission.jsonl 数据/processed/val_100_targets.jsonl
```

模型合并在不同环境产生不同字节哈希，不声称两者权重字节相同；每个部署分别验收。源实验包含长系统停顿，训练日志中的 elapsed_seconds 是墙钟时间，不能称纯GPU计算时长。

## 平台入口

`participant/start.sh` 保留比赛要求的 `conda_env` 名称，只用于对应Linux镜像。普通本机直接用 Python 或聊天入口。依赖先准备，模型、分词器和两个分类器全放本地，再运行 `bash /root/participant/start.sh TEST_FILE RESULT_DIR`。正式比赛提交步骤和账号信息不放入公开候选。
