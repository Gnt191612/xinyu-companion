# 桌面启动修复 v2.0.1

旧桌面入口可能因临时目录不可用或 Python.NET 初始化失败而无法启动。新入口采用系统 Microsoft Edge 应用窗口，保留开场动画与本机聊天界面；不再加载 Python.NET，也不需要运行时自解压。

已安装用户运行修复安装程序，选择原安装目录。若安装器本身无法创建临时目录，使用 ZIP 修复包，将全部内容解压覆盖到原安装目录；必须同时保留心语.exe 与 _internal 文件夹。修复包不含模型，不修改模型、适配器和配置。新用户须先安装 v2.0.0 完整包，再应用修复。

本机验收：在独立中文路径实际安装成功，退出码 0；将启动器的 TEMP/TMP 指向不存在的目录，仍能启动开场服务，页面 HTTP 200，状态 ready=true、error为空，并复用现有 v24 聊天服务。本机窗口显示已由用户确认；这不代表已完成干净系统或所有电脑的验收。

构建便携入口（项目根目录执行）：

```powershell
python -m PyInstaller --noconfirm --onedir --windowed --name 心语 --distpath tmp/桌面便携修复 --workpath tmp/desktop-portable-build --specpath tmp/desktop-portable-build --icon 体验/assets/心语.ico 体验/desktop_edge.py
```

用 tools/build_desktop_fix.py 的 --desktop 指向生成的心语目录，--project 指向项目根目录，--output 指向发行输出目录，--compiler 指向 Inno Setup 的 ISCC.exe。完整安装构建 tools/build_installer.py 同样需要 --desktop 参数，并使用新的空暂存目录；旧 desktop_app.py 为历史入口，不再用于发行。
