# 当前模型说明

当前第二版使用 Qwen2.5-3B-Instruct 与 v24 coverage_round step160 LoRA。体验版和比赛版共用该权重，体验版在回复字段生成完整后返回；比赛版生成完整输出结构。基座来源与许可见 模型来源.json 与 licenses/。

情感与画像分类器独立于生成模型：当前情感依据最新用户消息，画像参考最近8条用户消息。分数尚未校准，类别会误判。最多20轮会话，可重新开始；未实现持久长记忆或专业心理诊断。

最新本机正式入口三条冒烟输出解析成功，平均约5.69秒，不代表100条正式测评、隐藏集表现或所有硬件速度。历史第一版固定前100条生成指标及2354点分类指标只作为历史资料。

微调数据为 AI 辅助合成与少量官方回放，样本规模有限。曾发现角色/人称混淆、发表观点变成倾听、无依据休息建议和表达单调；专项优化不意味着这些错误永久消失。开发集选轮与最终独立验收须区分。官方第二次提交目前待测评。

公开前应审查官方派生资源、模型及素材再分发许可。通用语言能力来自千问，不宣称自主从零预训练。Qwen3B采用研究许可证，不能宣传无条件商用。
