# 模型说明

## 用途与组成

中文情感陪伴对话的课程实验与参赛实现。生成回复使用Qwen2.5-1.5B-Instruct合并LoRA；当前情感使用最新用户消息的TF-IDF/逻辑回归；画像使用最近8条用户消息分类器。记忆引用固定为空，因为未取得公开记忆库。

## 数据与评估口径

官方训练集8338段对话，排除4个轮次倒置点后18653个训练点；独立验证集900段对话/2354点，没有完全相同的训练验证对话。分类器评估全部2354点；生成指标只评估固定前100点。训练只使用2048个短目标点，验证答案不进入训练。

同卡40步/512步的回复诊断比较见 `results/云端40步指标.json`、`results/云端512步指标.json`。当前情感和画像模块固定，所以两生成模型的情感准确率相同不代表生成模型没有变化。两轮学习率不同，不能单独解释为训练步数收益。

## 已知局限

情感类别不平衡，焦虑、害怕、无助等容易混淆；画像空标签较多，集合匹配率须连同micro F1和空标签基线解读。回复可能过长，遇到紧迫期限时可能给出不合适的休息建议。字符重合提高不保证共情或建议质量；本地未计算BERTScore和官方总分。

JSON解析恢复次数仍如实记录，非空输出不等于所有生成结构首次合法。聊天默认最多20轮，没有持久记忆和联网知识。该实验不用于诊断、治疗或其他专业决策。

## 来源与透明度

开发和文档整理使用AI辅助。基座、官方工程和自有修改分别列于第三方来源。模型权重和官方数据不在当前源码包中。最终官方测评结果待核实后单独补充，不将排队状态或自测写成已获排名。
