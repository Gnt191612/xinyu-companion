# 心语本机体验

双击根目录的启动聊天体验.cmd，模型加载完成后打开 http://127.0.0.1:7860 。已在运行时直接打开页面即可。

本版使用白色樱花猫娘的编辑插画、樱花粉与浅紫配色、人物侧栏、通透聊天面板、头像、输入提示与移动端布局。Enter发送、Shift+Enter换行；右上角“重新开始”清空当前对话、输入和轮数，重新获得20轮额度；一轮指一条用户消息及对应的一条回复，发送失败不计入轮数。满20轮后暂停发送并提示重新开始。情感与画像分析折叠在每轮回复下方。

日常体验使用独立的温柔陪伴提示，按模型训练时的格式传递多轮历史，并补充体验专用的语气要求，鼓励具体共情、短回复、单个轻柔问题与尊重“不要建议”的偏好。已训练的512步权重和监督分类器保持不变，没有再次微调。比赛推理入口和提交镜像保持原配置；日常体验结果不能当作原比赛提示的公平对照指标。

角色是AI对话伙伴，ChatGPT元素仅为视觉创作。回复质量受小模型与训练规模限制，提示词不保证所有轮次都遵循指定语气。

临时微信分享已关闭。图像来源与编辑提示见assets/素材说明.md，未经确认原图的使用权限，不将这份角色素材纳入公开源码包。

语气配置位于陪伴提示.txt，每次请求读取，可独立调整而不重新加载权重。体验生成上限为384个新token，重复惩罚1.05。采用训练时的JSON输出格式，页面只显示解析出的回复正文；比赛入口未修改。实测记录保存在实验/体验语气验收_训练格式.json。该版本减少了长篇说教并尊重不要建议的要求，但仍有回复过短、安慰生硬的局限。更强的提示在测试中导致重复和编造，因此未采用；温柔贴心的目标尚未完全达成。

全景版本使用assets/樱花全景.png覆盖整个视口，人物区不再单独铺设竖图；聊天面板可透见连续窗格与樱花。该扩图同样不进入公开源码候选。

## 当前樱花动态版

双击根目录“心语樱花版.exe”打开桌面窗口；网页打开方式继续可用。新版背景为樱花场景加透明人物层，带呼吸、等待和回复动作及可关闭的花瓣粒子；人物不是Live2D骨骼模型。开场增加流光、轨道和花瓣。启动图标为重新绘制的猫娘特写。文字保留换行，连续英文可折行。

此前“没有再次微调”对应旧体验。现已完成云端v2和本机v3/v4补充训练，但整套候选未通过语义验收，未全面替换默认模型。当前config.json仅为已有上下文的明确短确认启用v2适配器，使用确认提示.txt直接生成正文；普通对话禁用适配器，保留原512模型。单句首次确认仍走原入口。上下文确认实测0.47/0.70秒，详细验收和失败候选见交付材料/樱花版升级说明.md。不能把短确认修复宣称为整体表达质量已达标。

服务并行响应页面连接，但模型生成仍串行，避免空闲浏览器预连接挡住其他请求；并发时须计入实际排队时间。
